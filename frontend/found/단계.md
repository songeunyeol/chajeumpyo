# 찾은 사람 단계

왼쪽 페인 작업이다. 이 파일 순서대로 `시안-리뷰/found/` 안에 HTML만 만든다.

피그마에 올리지 않는다. 전표는 만들지 않는다. 로그인, 회원가입, 인증 코드는 만들지 않는다. 찾은 사람은 가입하지 않고 사진만 올린다.

## 손대지 말 것

- `lost/` 전체
- `palette.css`, `paper.svg`, `팔레트.html`
- `index.html` 본문. 예외는 아래 한 줄뿐이다.

1번 화면을 만든 뒤에만 `index.html`의 찾은 사람 문을 바꾼다.

```html
<a class="door door-find" href="found/consent.html">
```

클래스, 글자, 아이콘, 다른 문은 그대로 둔다.

## 화면 껍질

`lost/login.html`과 같은 머리글을 쓴다. 스타일은 `../palette.css`만 링크한다.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/variable/pretendardvariable-dynamic-subset.min.css">
<link rel="stylesheet" href="../palette.css">
```

본문은 `<main class="screen">`. 제목은 `h1`, 보조 문장은 `lead`, 하단 버튼은 `dock` 안의 `btn`. 카드는 `card`, 건물 행은 `choice`, 고른 건물은 `choice on`. 새 색, 새 서체, 그림자, 아이콘 라이브러리를 넣지 않는다.

뒤로 가기는 첫 화면만 `../index.html`, 나머지는 이전 단계 파일이다.

## 넣지 말 것

- 숨은 특징 값, 색 입력, 점수, 순위, 카테고리 입력칸
- 정확한 좌표, 복도 번호, 층으로 자리를 짚는 문장
- 진짜 사진, 진짜 학번, 학생증 번호
- 저장 버튼
- 이미 가입된 이메일이라는 문장
- 네이버 지도 로고가 들어갈 오른쪽 아래를 가리는 버튼

표본은 무선 이어폰, 혜인관, 10월 23일(금) 14:10. 건물은 혜인관, 유담관, 청운관, 북악관, 본관, 한림관.

## 단계

1. `consent.html` 동의. 제목 `두 가지를 확인합니다`. 체크 두 개. 사진 외부 AI는 종류와 색을 읽고, 얼굴과 카드 번호는 보내기 전에 가린다. 위치는 가장 가까운 건물만 남기고 좌표는 저장하지 않는다. 버튼 `동의하고 계속` → `photo.html`.
2. `photo.html` 사진 한 장. 제목 `물건을 찍어 주세요`. 리드 `한 장이면 돼요`. 빈 사진 칸은 `photo`. 버튼 `이 사진으로` → `uploading.html`.
3. `uploading.html` 올리는 중. 제목 `올리고 있어요`. 리드 `종류를 읽는 중이에요`. 버튼 `다음` → `register.html`.
4. `register.html` 등록. 제목 `어디에 두었나요`. 물건 이름은 읽기 전용 `무선 이어폰`. 건물은 `choice on`으로 `혜인관`, 오른쪽 글자 `고치기`, 링크는 `buildings.html`. 작은 글자 `한 번 누르면 건물을 고쳐요`. 보관은 두 줄. `그 자리에 둠` → `done-inplace.html`. `보관처에 맡김` → `done-handover.html`. 색과 점수 칸은 없다.
5. `buildings.html` 건물. 제목 `어느 건물인가요`. 리드 `건물만 골래요. 좌표는 남지 않아요`. 여섯 건물. 혜인관만 `choice on`. 모두 `register.html`로 돌아간다.
6. `map.html` 건물 핀. 제목 `주운 건물`. 리드 `핀은 건물만 표시해요`. 지도 자리에는 건물 이름 여섯만 카드로 둔다. 실제 지도 키는 넣지 않는다. 화면 오른쪽 아래는 비운다. 링크 `목록으로 고치기` → `buildings.html`. 등록 화면에서는 이 파일을 바로 열지 않는다. `board.html`에서만 연다.
7. `done-inplace.html` 그 자리에 둠. 제목 `올려 두었어요`. 표에 주운 곳 `혜인관`, 보관 `그 자리에 둠`, 시각 `10월 23일(금) 14:10`. 노트 `이 사진 링크는 10분 뒤 닫혀요. 저장 버튼은 없어요`. 버튼 `처음 화면` → `../index.html`.
8. `done-handover.html` 보관처에 맡김. 제목 `센터에 맡기면 돼요`. 표에 보관 `보관처에 맡김`, 맡긴 곳 `종합서비스센터`와 `혜인관 1층 정문 옆`. 같은 10분 노트. 버튼 `처음 화면` → `../index.html`.
9. `done-advice.html` 귀중품. 제목 `그 자리에 두지 마세요`. 리드 `귀중품은 종합서비스센터에 맡겨 주세요`. 버튼 `보관처로 바꾸기` → `done-handover.html`. 이 화면도 `board.html`에서 연다.
10. `board.html` 단계 목록. 1부터 9까지 위 파일로 링크. 뒤로는 `../팔레트.html`.

끝나면 `found/board.html`을 브라우저에서 1번부터 눌러 링크가 이어지는지 확인한다.
