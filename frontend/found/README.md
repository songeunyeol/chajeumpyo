# 찾은 사람

왼쪽 페인이 이 폴더만 만든다. 화면 순서와 문구는 `단계.md`만 따른다.

`lost/`와 `palette.css`, 메인 본문은 고치지 않는다. 1번 화면을 만든 뒤에만 `index.html`의 찾은 사람 문을 `found/consent.html`로 바꾼다.

## 로컬에서 띄우기

- 백엔드: `npm run dev -w backend` (기본 4000 포트, `.env`의 `PORT`로 바꿀 수 있다)
- 화면: `frontend/`를 정적 서버(VS Code Live Server 등)로 **5500 포트**에 띄운다. 이때 `api.js`가 이 페이지를 연 호스트의 **4000 포트** API(`http://<호스트>:4000/api/v1`)로 자동 연결한다. 휴대폰에서 `http://<PC IP>:5500/...`로 열어도 그 PC의 4000 포트로 붙는다.
- 다른 포트로 띄우거나 백엔드 포트가 다르면 주소 뒤에 `?api=http://<PC IP>:4000/api/v1`를 한 번 붙인다. 이 값은 탭을 닫을 때까지(sessionStorage) 기억한다.
- 배포에서는 백엔드가 화면도 같이 내려주므로 같은 주소의 `/api/v1`을 쓴다(설정 필요 없음).
