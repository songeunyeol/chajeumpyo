## 기획 배경 및 제작 목적 (기획 배경 500자 이내 / 제작 목적 400자 이내)

**기획 배경**

서경대 캠퍼스의 분실물은 종합서비스센터·경비실·학과 사무실·커뮤니티 게시글로 흩어져 있어, 잃어버린 학생은 어디를 찾아야 할지 모르고 주운 학생은 맡기러 가거나 글을 쓰는 일이 번거로워 그냥 두고 가기 쉽다. 커뮤니티에 사진을 그대로 올리면 학생증·카드의 이름과 번호가 노출되고, 주인이 아닌 사람이 "제 거예요"라고 가져가도 막을 방법이 없다. 누가 찾아갔는지 기록도 남지 않는다. 같은 건물·시간대에 분실이 반복돼도 이를 모아 보는 사람이 없어 예방 안내로 이어지지 않는다. 전국 경찰서 유실물도 2020년~2024년 7월 495만 건 중 주인을 찾은 비율이 60.4%에 그쳤다(경찰청 자료, KPI뉴스 2024.9.16). 【팀 입력: 교무처 접수·반환 현황이나 에타 분실물 글 수 1개】

**제작 목적**

사진 한 장으로 등록하고, 주인만 아는 특징으로 찾아가는 캠퍼스 분실물 서비스를 만든다. ① 습득자는 가입 없이 사진만 올리면 AI가 종류·색·숨은 특징을 정리한다. ② 사진 속 얼굴·카드 글자는 외부 AI로 보내기 전에 서버에서 먼저 가린다. ③ 분실자는 설명한 특징이 숨겨진 정보와 맞아야만 사진과 보관 위치를 볼 수 있다. ④ 수령은 교무처 QR로 기록을 남긴다. ⑤ 건물·시간대·종류별 분실 다발 구간을 보여 줘 예방 조치로 잇는다. 불편이 문제가 되기 전에 탐지·예측·해결하는 것이 목표다.

## 3. 주요 기능 및 특징 (링크 포함 / 1000자 이내)

서비스: https://chajeumpyo.onrender.com (첫 화면 "체험 안내", 분실자 "체험해 보기"로 가입 없이 시연) · 관리자: /admin/login.html ("시연으로 둘러보기") · 코드: https://github.com/songeunyeol/chajeumpyo

1) 사진 한 장 등록(탐지): 가입 없이 사진을 올리면 Gemini가 24개 종류·36개 세부 종류, 색, 숨은 특징을 뽑는다. 공개 사진 87장 시험에서 큰 종류 99%, 세부 종류 90%. 건물은 위치나 사진 위치로 추천한다.
2) 개인정보 가리기: 서버 안 감지 모델(얼굴·글자 영역)이 먼저 가린 사본만 AI로 보내고, 저장 원본도 가린다. 실패하면 AI로 보내지 않는다.
3) 후보 추천: 종류·장소·시간·설명 유사도로 상위 3개만, 흐린 사진과 공개 정보로 보여 준다.
4) 주인 확인(해결): 설명의 특징을 숨은 특징과 규칙으로 대조하고, 규칙이 다르다고 본 것만 AI가 같은 뜻인지 다시 본다. 애매하면 객관식 카드 질문(최대 2문제), 계정당 3회·물건당 10회 틀리면 잠근다. 시드 14개 평가에서 진짜 주인 42/42 통과, 사칭 0/14.
5) 수령·기록: 교무처가 QR을 찍어 돌려주고 열람·수령 계정을 남긴다.
6) 반복 분실 탐지·우선순위(예측): 건물·시간대·종류로 반복된 분실과 반복된 분실 신고를 찾아 우선순위, 다음 7일 예상, 예방 조치를 제안하고, 높음이 되면 교무처에 미리 알린다.
7) 앱 내 알림, 홈 화면 설치(PWA), 심사용 체험 모드(시드 14건)와 체험 안내 화면(/guide.html).

## 4. 개발 환경 및 사용 기술 (1000자 이내)

· 화면: HTML·CSS·JavaScript(프레임워크 없는 정적 페이지), PWA(매니페스트·서비스 워커), 네이버 지도 API(위성)
· 서버: Node.js 22, Express 5, TypeScript, zod(입력·AI 응답 검증), JWT
· DB: PostgreSQL + pgvector(임베딩 검색), Prisma 7. 공개 정보와 비공개 정보(사진·특징·자세한 위치)를 테이블 단위로 분리
· AI: Google Gemini 3.6 Flash(사진 속성 추출·신고 분석·확인 질문 보기 생성, 실패 시 3.5 Flash), gemini-embedding-001(1536차원). 특징 대조와 판정은 같은 입력에 늘 같은 결과가 나오도록 규칙으로 처리
· 서버 안 개인정보 가리기: onnxruntime-node + 얼굴 감지(UltraFace RFB-320) + 글자 영역 감지(PP-OCRv4 det). 사진 한 장 약 0.1~0.15초
· 보안: Cloudflare Turnstile, 요청 횟수 제한, bcrypt, 만료 시간 있는 서명 URL
· 배포: Render(싱가포르) Docker 서비스 하나 + Render PostgreSQL. 비용(10/29 확인) Gemini ₩1,430, Render $0.40, 한 달 고정비 $17.75(Render 공시 가격)
· 품질: Vitest 자동 테스트 407개, Biome, GitHub Actions CI(Gitleaks 키 유출 검사 포함), 주인 확인 평가 스크립트(실제 Gemini)
· 협업: GitHub PR 리뷰, Notion, Claude Code(AI 코딩 도구, 정책 결정은 팀이 함)

## 5. 기대 효과 및 활용 방안 (600자 이내)

· 습득자는 설치·가입 없이 사진 한 장으로 등록해 맡기는 부담이 준다. 강의실·도서관에 QR을 붙이면 바로 등록 화면이 열린다.
· 사진·특징을 숨기고 주인만 아는 정보로 확인해, 남이 가져가는 일과 개인정보 노출을 줄인다. 열람·수령 기록이 남아 분쟁 때 확인할 수 있다. LOST112·학교 게시판·동네 커뮤니티는 사진 공개와 사람 확인에 맡기지만, 찾음표는 공개 전에 가리고 확인한다.
· 교무처는 수기 장부 대신 QR 스캔으로 반환을 처리하고, 반복 분실 구간의 우선순위와 제안된 예방 조치(안내문·순찰)로 문제가 커지기 전에 손쓸 수 있다.
· 활용·확장: 교무처 시범 운영 후 경비실 등으로 보관처 확대, 앱스토어 배포와 푸시 알림, 경찰청 LOST112 연동, 다른 학교로 확장(건물 목록·메일 도메인만 바꾸면 됨). 【팀 입력: 시범 운영 계획이 있으면 한 줄】
