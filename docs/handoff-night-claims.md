## 아직 증명되지 않은 것 / 남은 문제 (r2)
1. **흐린 썸네일 사칭(c) 7/29**: 질문 1개짜리 찍기가 썸네일로 보이는 특징(무늬, 링 모양, 줄무늬, 팩트 모양)만 물어서 맞힘.
   원인은 r2의 "찍기 최소 1문제" + "썸네일 특징을 뒤에서라도 씀"의 조합.
   - 제안: **찍기(맞힌 특징 0)는 질문 2개 이상, 그중 썸네일로 보이는 것은 최대 1개**. 못 채우면 근거 부족.
     주인은 대부분 특징을 하나 이상 맞혀 찍기가 아닌 길로 가므로 주인 통과에 영향이 작을 것으로 봄(측정 필요).
   - 흔한 특징만 맞힌 설명(b, passBlocked)도 질문 1개짜리가 되지 않게 2개 이상 요구.
2. **MK 지갑 e "나이키 로고" 통과**: 브랜드 질문 보기에 `마이클 코어스 (TFAMGLK PYYG)` 같은 깨진 오답이 섞여 정답이 드러남(보기 생성 문제),
   그리고 #18 2부가 이 경우 실패로 세지 않음(브랜드 확인 결과 DIFFERENT가 안 나온 것으로 보임). 둘 다 확인 필요.
3. **주인 실패 8건**: 회색 인형 키링 3(사진 가리기가 인형 얼굴을 사람 얼굴로 가려 특징이 없음, 예전부터의 문제),
   아이패드 2(모순으로 바로 실패: 케이스 색·커버 색 대조 확인 필요), 에어팟·휴대폰·털 파우치 각 1.
4. #18 2부를 끈 상태의 r2 주인 수치는 재지 않았음.

## 평가 다시 돌리는 법
1. 로컬 임시 Postgres(pgvector)를 따로 띄운다. **개발·운영 DB에 대고 돌리지 말 것** (시작할 때 신고·시도를 모두 지움).
2. 환경: `DATABASE_URL`(임시 DB), `AI_MODE=gemini`, `NODE_ENV=development`, `CAPTCHA_MODE=off`, `AI_TIMEOUT_MS=20000`,
   `ALLOWED_EMAIL_DOMAINS=skuniv.ac.kr`, `JWT_SECRET`(아무 값), `STORAGE_LOCAL_DIR`(임시 폴더). Gemini 키는 루트 `.env`.
   #18 2부를 끄려면 `CLAIM_BRAND_HARD_CONTRADICTION=false`.
3. `cd backend && npx prisma migrate deploy && npx tsx --env-file=../.env prisma/seed.ts`
4. 사진 폴더는 팀 사진(레포 밖, 파일 이름 끝 세 자리 숫자 = labels의 `photo`)을 쓴다.
   ```
   npx tsx --env-file=../.env scripts/eval-night-claims.ts register  <사진폴더> scripts/eval-night-claims.labels.json <out>
   npx tsx --env-file=../.env scripts/eval-night-claims.ts owners    <사진폴더> scripts/eval-night-claims.labels.json <out> r3
   npx tsx --env-file=../.env scripts/eval-night-claims.ts impostors <사진폴더> scripts/eval-night-claims.labels.json <out> r3
   ```
   owners·impostors는 같은 DB를 지우므로 **동시에 돌리지 말고 차례로**. 결과는 `<out>/owners-r3.json`, `impostors-r3.json`.
   비용은 한 바퀴(등록 + 주인 + 사칭) 약 1~2달러, 30~40분.
