# 심사위원용 체험 시나리오

> 기준: 기능 명세 F-05(체험 로그인), F-06~F-11. 시드 데이터: `backend/src/services/demo-seed.ts`의 `DEMO_SEED_ITEMS`.
> 여기 적힌 숨은 특징은 **이 문서와 시드 코드에만** 있다. 화면의 후보 목록에는 종류·건물·습득 시각과 강하게 흐린 사진만 나온다.
> 시드 값을 바꾸면 이 문서도 같이 고친다.

## 1. 준비 (운영자)

```bash
npm run db:deploy -w backend   # 마이그레이션
npm run db:seed -w backend     # 건물·보관처 (prisma/seed-data). 시드보다 먼저
npm run seed:demo -w backend   # 체험용 시드 습득물 8개
```

- `seed:demo`는 고정 id로 넣어서 **여러 번 돌려도 늘지 않는다.** 돌릴 때마다 상태·속성·사진·습득 시각을 처음 값으로 되돌리므로, 시연 직전에 한 번 더 돌려도 된다.
- 임베딩은 서비스와 같은 `ai.embed`로 만든다. `AI_MODE=gemini`이면 Gemini 호출이 8번 일어난다.
- **임베딩은 `seed:demo`를 돌린 그때의 `AI_MODE`로 만들어진다.** `mock`으로 넣은 뒤 서버만 `gemini`로 바꾸면 시드 임베딩(mock)과 신고 임베딩(Gemini)이 서로 다른 공간이라 후보 순위가 엉망이 된다. **`AI_MODE`를 바꿨으면 `seed:demo`를 반드시 다시 돌린다**(습득 시각이 1시간마다 당겨지는 것과 달리 임베딩은 저절로 다시 만들어지지 않는다).
- 사진은 실제 사진이 아니라 코드로 그린 그림(SVG → sharp)이고, 실제 등록과 같은 사진 처리(정리 → 공개본 → 후보용 블러본)를 거쳐 같은 저장소에 들어간다. 사람·학번·카드 번호는 없다. 배포로 사진 폴더가 비었으면 다시 돌리면 복구된다.
- 시드는 보관 기한이 없고(`expiresAt` 없음) 기한 만료·사진 삭제·기록 삭제 작업에서 빠진다.
- 후보는 "잃어버린 시각(시작) 이후에 주운 물건"만 나오므로, 서버가 한 시간마다 시드의 습득 시각을 **지금부터 1~8시간 전**으로 다시 당긴다(1번 물건이 1시간 전, 8번 물건이 8시간 전).
  - 그래서 심사위원은 잃어버린 시간의 **시작을 8시간보다 앞으로** 잡아야 모든 시드가 후보에 나온다. 예) "오늘 · 00:00 부터"(오늘 오전부터). 오전 8시 이전에 시연하면 날짜를 "어제"로 고른다.
  - 분실 신고 화면(`lost/report.html`)의 시간 기본값은 13:00~15:00이라, 그대로 두면 오후 시연에서도 일부 시드(13시 이전에 주운 것)가 빠질 수 있다. **시작 시간을 꼭 바꿔 달라고 안내한다.**
- 시드는 체험 계정의 후보에만 나오고, 일반 학생 계정에는 나오지 않는다.

## 2. 체험 순서

화면 이름은 `frontend/lost/`의 실제 파일 기준이다(잃어버린 사람 화면의 API 연결은 별도 PR에서 진행 중).

1. 첫 화면(`index.html`) → **잃어버린 사람** → 로그인(`lost/login.html`) → **체험해 보기**. 누를 때마다 새 체험 계정이 생겨서 시도 횟수가 심사위원마다 따로 계산된다(24시간 뒤 자동 삭제). 들어가면 내 분실 신고(`lost/home.html`) 위에 "체험 모드" 띠가 보인다.
   - 체험해 보기 버튼은 연결 PR에서 로그인 화면에 붙는다. 그 전에는 API(`POST /auth/demo`)로만 체험 계정을 만들 수 있다.
2. **분실 신고**(`lost/report.html`, "무엇을 잃어버렸나요"): 아래 표에서 물건 하나를 골라
   - 무엇: 표의 "종류"
   - 언제: **오늘 · 00:00 부터 ~ 지금 이후까지**(1절 참고. 시드는 1~8시간 전에 주운 것으로 되어 있다)
   - 어디(건물): 표의 "건물" (몰라도 됨. "잘 모르겠음"도 된다. 고르면 후보 근거에 "같은 건물"이 붙는다)
   - 기억나는 점: 표의 **숨은 특징**을 자연스럽게 적는다. 예) "흰색 에어팟이에요. 케이스에 곰돌이 스티커가 붙어 있어요."
   - **신고하기** → 올리는 중(`lost/uploading.html`) → 후보 화면으로 넘어간다.
3. **후보**(`lost/candidates.html`, "비슷한 물건 N개"): 흐린 사진과 종류·건물·습득 시각만 보인다. 그 물건에서 **내 물건인지 확인**.
4. **판정**: 신고에 적은 특징이 시드의 숨은 특징과 맞으면 바로 **통과**. 애매하면 확인 질문(`lost/question.html`)이 한 번 나오고, 남은 숨은 특징으로 답하면 된다. 틀리면 확인 실패(`lost/fail.html`, "아니에요").
5. **통과 후**("내 물건이 맞아요"): 선명한 사진, 층·자세한 위치, 보관처가 열린다.
   - 보관처에 맡긴 물건(`lost/item-handover.html`): 수령 QR을 받으면 관리자 스캔 없이 "시연: 보관처에서 수령 처리됨"으로 끝난다.
   - 그 자리에 둔 물건(`lost/item.html`): "찾았어요"로 끝난다.
   - 어느 쪽이든 **시드 상태는 바뀌지 않아** 다음 심사위원도 처음부터 같은 물건으로 체험할 수 있다.
6. (선택) **실패 체험**: 숨은 특징과 다른 설명(예: "검정 이어폰, 스티커 없음")으로 신고하고 시도하면 실패한다. 계정당 물건별 3번 실패하면 그 계정에서는 더 확인할 수 없다(`lost/lock.html`). 시드는 물건 전체 잠금(대면 확인)으로 넘어가지 않는다.

| --- | --- | --- | --- | --- | --- |
| 1 | 혜인관 3층 | 무선 이어폰 (무선 이어폰) | 흰색 · Apple | 케이스 앞면 **곰돌이 스티커**, 케이스 뒷면 **긁힌 자국** | 3층 엘리베이터 앞 벤치 위 · 교무처에 맡김 |
| 2 | 북악관 1층 | 지갑 (반지갑) | 갈색 · 없음 | 안쪽에 **J.H 각인**, **영화 티켓 한 장**이 들어 있음 | 1층 학생 라운지 소파 틈 · 교무처에 맡김 |
| 3 | 청운관 1층 | 우산 | 검정 · 없음 | **회색 줄무늬**, 손잡이에 **고양이 키링** | 1층 정문 우산꽂이 · 그 자리에 둠 |
| 4 | 유담관 5층 | 텀블러·물병 | 파랑 · 스탠리 | 옆면에 **펭귄 스티커**, **바닥이 찌그러짐** | 5층 강의실 창가 맨 뒷자리 · 그 자리에 둠 |
| 5 | 청운관 2층 | 휴대폰 | 검정 · Apple | **투명 케이스**, 케이스 안쪽에 **노란 별 스티커** | 2층 화장실 앞 정수기 위 · 교무처에 맡김 |
| 6 | 유담관 1층 | 열쇠 (자동차 키) | 검정 · 현대 | **갈색 가죽 키케이스**, **빨간 하트 키링** | 1층 주차장 출입문 앞 · 교무처에 맡김 |
| 7 | 한림관 2층 | 가방 (백팩) | 회색 · 없음 | 지퍼에 **노란 오리 인형 키링**, 앞주머니에 **별 모양 자수** | 2층 복사실 앞 의자 옆 · 그 자리에 둠 |
| 8 | 본관 4층 | 필기구·필통 (필통) | 분홍 · 없음 | 앞에 **딸기 스티커**, 안에 **초록색 형광펜** | 4층 열람실 입구 사물함 위 · 그 자리에 둠 |

- 종류마다 시드가 하나씩이라, 종류만 맞게 신고하면 후보에 그 물건이 나온다(연관 종류의 시드가 같이 나올 수 있다). 통과 여부는 숨은 특징으로 갈린다.
- 판정은 AI가 신고 설명에서 뽑은 특징과 시드의 특징을 대조한다. 표현은 달라도 된다("곰 스티커", "테디베어 스티커" 등).

## 4. 시연 중 문제가 생기면

| 증상 | 확인 |
| --- | --- |
| 후보가 하나도 안 나온다 | `seed:demo`를 돌렸는지, 체험 계정으로 들어왔는지(일반 계정에는 시드가 안 나옴), 잃어버린 시간의 시작을 8시간보다 앞(예: 오늘 00:00)으로 했는지 |
| 후보는 나오는데 엉뚱한 물건이 위에 온다 | `AI_MODE`를 바꾼 뒤 `seed:demo`를 다시 안 돌렸는지(시드 임베딩이 옛 방식) |
| 사진이 안 보인다 | 배포 후 저장소가 비었을 수 있다. `seed:demo`를 다시 돌린다 |
| 체험해 보기가 막힌다 (`429`) | 같은 IP에서 10분에 5개까지. 잠시 기다린다 |
| `CAPTCHA_FAILED` | 위젯 토큰이 만료됐거나, 배포 주소가 Turnstile 위젯의 허용 도메인·서버의 `PUBLIC_BASE_URL`(또는 `TURNSTILE_HOSTNAMES`)과 다르다. 화면을 새로 열어 다시 시도하고, 계속되면 두 설정을 확인한다 |
