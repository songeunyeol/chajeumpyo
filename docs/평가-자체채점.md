## 항목별 채점

### 1. 문제 정의의 명확성 (25) — 현재 14

- 근거: 결과보고서 2.1에 문제 4가지(분실물 장소가 흩어짐, 사진 공개 시 개인정보 노출·가로채기, 습득자의 번거로움, 수령 기록 없음)와 해결 방향 2.2.
- 부족: **숫자 근거가 하나도 없다** (2.1 [TODO]). 감점 3번("실제 캠퍼스 문제와 관련성 낮음")을 피하려면 실제 서경대 근거가 필요하다. 문제를 겪는 사람(습득자·분실자·교무처)별 불편이 한눈에 안 보인다.
- 올릴 방법 (시간당 점수 순)
  1. 【팀】 에브리타임 서경대 게시판 분실물 글 수(최근 1~3개월)를 세서 한 줄 + 캡처 — 30분, +3~4
  2. 【팀】 교무처(또는 종합서비스센터)에 분실물 접수·반환 방식, 한 달 대략 건수를 물어 한 줄 — 30분, +3
  3. 【팀】 구글 폼 설문 5문항(잃어버린 경험, 어디서 찾았는지, 커뮤니티 사진 공개에 대한 생각) 20명 이상 — 반나절, +2~3
  4. 【나】 사용자별 불편 표(습득자·분실자·교무처 × 지금 불편 × 찾음표가 바꾸는 것)를 보고서에 추가 — 15분, +1

### 2. AI·소프트웨어 활용성 (25) — 현재 20

- 근거
  - AI를 단계마다 이유와 함께 쓴다: 사진 속성 추출(Gemini, 모델 비교·속도·정확도 측정 7.3), 서버 안 가리기(ONNX 얼굴·글자 감지, AI 전송 전), 임베딩 후보 검색(pgvector), 객관식 보기 생성(Gemini, 실패 시 준비된 보기), 서술형 답 판정.
  - AI를 쓰지 않는 곳도 이유가 있다: 특징 대조·판정은 같은 입력에 같은 결과가 나와야 해서 규칙으로.
  - 반복 분실 탐지·우선순위(PR #76)로 목적 문구에 직접 대응.
- 부족: 후보 적중률(top-3)·가리기 정확도는 아직 측정하지 않았다(8.2, 테스트 세트 사진 필요). 단순 임베딩 검색 대비 비교(8.3)가 없다. 정확도 87장은 공개 제품 사진이라 실제 분실물 사진과 다르다.
- 올릴 방법
  1. 【팀】 실제 분실물처럼 찍은 사진 30장 + 설명(B6) → 【나】 종류 정확도·top-3 적중률·가리기 누락 측정, 8.2 표 채움 — 사진 받은 뒤 1시간, +2~3
  2. 【나】 같은 세트로 "임베딩만" 기준값 대비 우리 점수 비교(8.3) — 1시간, +1
  3. 【발표】 "AI를 어디에 왜 썼고 어디엔 일부러 안 썼는지" 한 장 슬라이드 — 감점 2·6번 방어

### 3. 서비스 기획 완성도 (15) — 현재 12

- 근거: 사용자 4종(습득자·분실자·관리자·체험) 흐름이 4.1에 표로 있고 화면도 모두 연결됨. 공개/비공개 정보 분리, 두 단계 등록, 시도 제한, 수령 기록이 한 흐름으로 이어진다. 구조도(6.2) 있음.
- 부족: 화면 캡처(4.3 [TODO]). QA에서 나온 화면 문구·흐름 문제를 10/29에 고쳤지만(PR #71~#73) 실제 휴대폰 재확인 전.
- 올릴 방법
  1. 【팀/나】 QA 수정 반영된 화면 캡처 7장을 보고서·PPT에 — 30분, +1
  2. 【나】 사용자 흐름 그림(습득자 → 분실자 → 관리자 한 장) — 20분, +1

### 4. 구현 완성도 (20) — 현재 16

- 근거: 운영 서비스가 실제로 동작(Render, health 200). 네 흐름 모두 연결, 체험 모드(시드 14건)·관리자 시연 모드로 심사위원이 가입 없이 시연 가능. 자동 테스트 400개, CI.
- 부족: 실제 휴대폰 두 대로 QR 수령 전 과정 재확인 전(QR 버그는 PR #72에서 수정). 학교 메일에서 인증 메일이 스팸함으로 갈 수 있음. **시연 영상이 아직 없다** (필수 제출물).
- 올릴 방법
  1. 【팀】 시연 영상 2~3분 녹화 (결과보고서 "시연 영상 시나리오" 따라) — 1~2시간, 제출 필수 + 감점 5번 방어
  2. 【윤호】 휴대폰 두 대로 습득 등록 → 분실 신고 → 확인 → QR 수령 한 번 끝까지 — 20분, +1~2
  3. 【나】 자동 흐름 점검(E2E) 결과를 보고서 8.5에 한 줄 — +0.5

### 5. 실현 가능성 및 확장성 (15) — 현재 11

- 근거: 실제 비용 측정(Gemini ₩1,430, Render $0.40, 10/29), 보관처를 교무처 한 곳으로 정해 운영 단순화, 다른 학교 확장(건물 목록·메일 도메인 설정), LOST112 코드 매핑, Capacitor 앱 계획, 반복 분실 → 예방 조치로 운영 개선 고리.
- 부족: 교무처와 실제 협의 흔적이 없다. 한 달 운영비 추정 근거(요금제 가격)가 보고서에 없다.
- 올릴 방법
  1. 【팀】 교무처에 서비스를 보여 주고 한 줄 의견 받기(가능하면) — +2
  2. 【나】 Render 요금제 공시 가격으로 한 달 고정비 계산(출처 링크) — 15분, +1
  3. 【나】 운영 시나리오(교무처 하루 업무 흐름: 아침 검토 대기 → 수령 QR → 주간 "먼저 손볼 곳" 확인) — 15분, +1

## 사람이 해야 점수가 오르는 것 (우선순위)

1. 시연 영상 녹화 (필수 제출물)
2. 문제 정의 근거 숫자 1~2개 (에타 글 수, 교무처 접수 현황)
3. 실제 사진 30장 + 설명 → 정확도·적중률 측정
4. 휴대폰 두 대로 QR 수령 끝까지 확인
5. 화면 캡처, 역할 분담, 공모전 주제 문구 확인
