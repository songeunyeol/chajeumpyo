봇 조사 초안 · 2026-10-10 · 3D·길찾기는 범위 밖

## 추천

**Leaflet + 건물 폴리곤(또는 캠퍼스 평면도 이미지 오버레이) + 건물 단위 마커**

- P0는 "어느 건물인지"만 필요. 실내 층·복도·경로 탐색은 하지 않음.
- Leaflet은 의존성·용량이 작고, 이미지 오버레이·GeoJSON 폴리곤·마커에 충분함.
- MapLibre GL은 벡터 타일·실내 플러그인에 강하지만, 지금 데이터(건물 목록)에는 과함.

## 데이터

| 필요 | 방식 |
| --- | --- |
| 건물 위치 | 건물명 → 폴리곤 또는 중심점 GeoJSON (손작업 가능) |
| 배경 | OSM 타일(Leaflet 기본) 또는 학교 제공 캠퍼스맵 이미지 |
| 층 전환 | 하지 않음 (P1 이후) |

## 하지 않을 것

- 3D 건물, 실내 길찾기, MapLibre indoor 플러그인, Google Maps 유료 SDK

## 회의에서 받을지

이견 없으면 Leaflet 2D로 확정. 학교 공식 CAD/도면이 있으면 이미지 오버레이로 교체.
