| 용도 | 모델 |
| --- | --- |

## 모델 설정 (10/29 조정)

| 설정 | 값 | 이유 |
| --- | --- | --- |
| `GEMINI_MODEL` | `gemini-3.6-flash` | 기본 |
| `GEMINI_FALLBACK_MODEL` | `gemini-3.5-flash` | 기본 모델이 오류·형식 오류일 때 한 번 더 |
| `GEMINI_THINKING_LEVEL` | `MINIMAL` (기본값) | 3.x Flash는 생각하는 모델이라 기본값으로 두면 사진 1장 중앙값 5.8초·최대 14.6초. `MINIMAL`로 낮춰도 정확도가 줄지 않았다(아래 측정) |
| 생각 정도 적용 범위 | 사진 분석·분실 신고 분석만 | 확인 질문 답 판정(MATCH/NO_MATCH)은 보안 판단이라 모델 기본값 그대로 둔다 |
| `AI_TIMEOUT_MS` | 코드 기본 8000 | `MINIMAL`에서 최대 5.2~8.4초라 운영은 12000 정도를 권장(지금 운영 20000도 문제없음). 시간 초과 시 서비스가 `retryOnce`로 한 번 더 부르므로, 시간 초과에 대체 모델을 따로 붙이지 않았다(느린 원인은 대개 같은 인프라 혼잡이라 대체 모델도 느리고, 호출만 두 배가 된다) |

`DEFAULT`로 두면 생각 설정을 보내지 않아 모델 기본값을 쓴다(되돌리기용).

### 종류 인식 측정 (10/29, 유료 등급)

`npm run eval:categories -w backend -- ~/Desktop/chajeumpyo-test-photos-web` — Wikimedia 등 자유 라이선스 사진 87장(출처 `_출처.json`), 서비스와 같은 순서(정리 → 가리기 → AI). 걸린 시간은 AI 호출만.

| 설정 | 큰 종류 | 세부 종류 | 중앙값 | 최대 |
| --- | --- | --- | --- | --- |
| 생각 기본값 + 이전 지시문 (기준) | 95% (83/87) | 85% (57/67) | 5.8초 | 14.6초 |
| `MINIMAL` + 이전 지시문 | 98% (85/87) | 87% (58/67) | 3.0초 | 8.4초 |
| `MINIMAL` + 규칙 7줄 시도 (버림) | 95% (83/87) | 85% (57/67) | 2.6초 | 19.0초(1장, 네트워크 튐) |
| **`MINIMAL` + 최종 지시문 (채택)** | **99% (86/87)** | **90% (60/67)** | **2.6초** | **5.2초** |
| `LOW` + 최종 지시문, 30장 부분집합* | 93% (28/30) | 67% (16/24) | 2.8초 | 4.0초 |
| `MINIMAL` + 최종 지시문, 같은 30장* | 97% (29/30) | 75% (18/24) | 2.6초 | 3.6초 |

\* 30장 = 4장마다 1장 + 헷갈린 사진 10장. 어려운 사진을 일부러 넣어 전체보다 낮다. `LOW`는 더 느리고 더 맞지도 않아 전체로 돌리지 않았다.

**지시문 변경 (최종)**
- 사진의 회색 단색 상자는 서버가 미리 가린 자리라는 것, 가린 자리만으로 신분증·카드로 보지 말 것. 메모리스틱 사진이 가리기 뒤 글자가 모두 회색 상자가 되어 `ID_CARD`로 나오던 문제(가리기의 부작용)를 고쳤다.
- 메모리카드(SD·메모리스틱)는 `CHARGER/USB_MEMORY`, `ID_CARD`는 이름·사진이 들어가는 카드만.
- 머리띠로 귀를 덮으면 무선이어도 `HEADPHONE`.
- 지퍼 주머니: 필기구가 보이거나 길쭉하면 `PENCIL_CASE`, 아니면 `POUCH`, 헷갈리면 다른 쪽을 `categoryAlt`로(큰 종류가 달라 후보 검색에 2순위가 중요).
- 가방·지갑 세부 정의, 교통카드 로고, "노트북 자판만 찍혀도 LAPTOP" 규칙도 시도했지만 나아지지 않아(교통카드 로고는 가리기로 지워짐) 넣지 않았다.

**남은 오답 7장** — 대부분 정답 라벨 자체가 애매하다.
- `무선 이어폰_3` → 헤드폰: 사진이 AirPods Max(머리띠형)라 모델 답이 맞고 라벨이 틀렸다.
- `반지갑_2·3` → 장지갑, `카드지갑_3` → 반지갑: 지갑 크기·접는 방식이 사진만으로 애매.
- `백팩_3` → 숄더백(철망에 걸린 여러 물건 장면), `에코백_2` → 숄더백(상자형 천 토트).
- `필통_2` → 파우치: 무늬 지퍼 주머니. 큰 종류도 달라진다(STATIONERY↔BAG).

**주의 (결과 해석)**
- 사진 대부분이 흰 배경 제품 사진이라 실제 분실물(어두운 강의실, 일부만 보임, 흐림)보다 쉽다. 실제 정확도는 이보다 낮을 수 있다.
- 학생증·신분증 사진은 개인정보 때문에 세트에 없다. 가리기 관련 지시문이 실제 학생증 인식에 영향을 주는지는 따로 확인해야 한다.
- 지시문 조정과 평가를 같은 87장으로 했으므로 홀드아웃이 아니다. 같은 설정도 돌릴 때마다 1~2장씩 답이 바뀌었다(온도 0이어도).
- 기준 측정과 `MINIMAL` 첫 측정은 동시에 돌려 걸린 시간이 약간 부풀었을 수 있다.

## 비용 메모

- **Gemini 3.6 Flash**: 무료 티어 있음. 2.5 계열은 새로 만든 키에서 쓸 수 없다(10/26 확인). 무료 티어는 붐빌 때 503·수십 초 지연이 잦아 시연·운영은 유료 등급 권장. 가격은 공식 가격표 확인
- **gemini-embedding-001**: 설명문(텍스트) 임베딩만 쓴다. 가격은 공식 가격표 확인
- 생각 정도를 `MINIMAL`로 낮추면 생각 토큰(출력 요금)이 줄어 호출당 비용도 내려간다.
- **GPT-4o**: $2.50 / $10 (1M 토큰당) — 대안이지만 너무 비쌈
- **gpt-4o-mini**: $0.15 / $0.60 (1M 토큰당) — 비상용 폴백 후보
- **Ultralytics YOLO**: AGPL 라이선스 문제로 사용하지 않음
- **로컬 CLIP**: 보고서용 베이스라인 비교로만 사용

## 보안·개인정보

- 무료 티어 데이터는 Google이 모델 개선 등에 사용할 수 있으므로, 전송 전 카드 번호·이름·얼굴 등은 마스킹한다.
- 모델 출력은 JSON 스키마를 강제하고 서버에서 다시 검증한다.
- 숨김 특징은 절대 클라이언트로 보내지 않는다.
- 위치는 건물 단위만 저장하고 원본 좌표는 저장하지 않는다(폐기).
