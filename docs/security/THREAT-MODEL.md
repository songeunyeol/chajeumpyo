# 위협 모델 (chajeumpyo)

> 범위: P0 (습득물 등록, 분실 검색·매칭, 본인 확인, 교내 지도, 관리자 대시보드). 방어 관점 문서. 운영 값(잠금 기준값, 확인 질문 문구, 관리자 이메일, 키)은 여기 적지 않고 환경변수·서버 설정으로 둔다.

## 1. 보호할 자산
| 자산 | 위치 | 비고 |
|---|---|---|
| 숨겨 둘 특징 | 서버 DB 전용 | 클라이언트·매칭 응답에 절대 포함 금지 |
| 정확한 보관 위치 | 서버 DB | 본인 확인 통과 후에만 공개 |
| 습득물 사진 원본 | 스토리지(비공개) | 업로드 시 마스킹·EXIF 제거본만 사용 |
| 학교 이메일·수령 기록 | 서버 DB | 최소 수집, 보관 기간 후 삭제 |
| API 키(Gemini, LOST112) | 서버 환경변수 | 레포·노션·클라이언트 금지 |
| 관리자 권한 | 서버에서 부여한 역할 | 공유 비밀번호 금지 |

## 3. 개인정보 원칙
- 수집: 가입 이메일(분실자만 가입, 학교 이메일 아니어도 가능, 인증 코드 필수), 수령 기록(이메일·시각·물건 ID). 습득자는 가입 없이 등록. 이름·신분증·카드 정보는 받지 않는다.
- 동의: 이메일 수집, 위치 사용, 사진의 외부 AI 처리 3가지를 한 화면에서 받는다.
- 보관(확정): 수령 시 사진·설명·특징 즉시 삭제, 미수령은 등록 30일 뒤 삭제. 확인 시도 기록과 찾아간 사람 기록은 30일 보관 후 삭제. 삭제는 스케줄 작업으로 하고 스토리지 원본·블러 사본까지 함께 지운다.
- LOST112 시드: 사진은 복사하지 않고 링크 + "출처: 경찰청 LOST112", 화면에 "외부 공공 데이터" 표시.
- 테스트 사진 100장: 실제 카드번호·학생증·얼굴 금지, 필요하면 가짜 카드 사용.
